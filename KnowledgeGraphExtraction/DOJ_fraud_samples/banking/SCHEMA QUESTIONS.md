# Schema questions (banking)

Paste the lines in the block below into **Questions this graph should answer** before clicking *Infer schema*,
and leave them there for the ingest: they steer both schema inference and extraction.
They say what the graph must answer, so the inferred schema keeps the relationships and numbers the questions in
`BANKING FRAUD QUESTIONS to ASK.md` need. They are general on purpose, so they do not copy the test questions.

```text
Who were each defendant's co-defendants?
Which judge presided over each defendant's case?
What was each defendant charged with, what is the plea status, and which charges are still pending?
What is the maximum prison term for each crime?
Which bank did each defendant defraud, and for how much?
Which prosecutors (people) prosecuted each defendant, and which agencies investigated them?
How old is each defendant, and when is their sentencing date?
```
